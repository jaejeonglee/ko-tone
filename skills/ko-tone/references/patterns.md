## 1. 번역투

| 원문 | 문제 | 고친 예 |
| --- | --- | --- |
| 보안 감사에 있어서 가장 중요한 것은 | "~에 있어서"는 영어 in/for 직역 | 보안 감사에서 가장 중요한 것은 |
| 이 기능에 대한 설명을 드리겠습니다 | "~에 대한" + 돌려 말하기 | 이 기능을 설명하겠습니다 |
| API를 통해 데이터를 가져옵니다 | 수단이 분명하면 유지해도 된다 | API로 데이터를 가져옵니다 |
| 트랜잭션은 시퀀서에 의해 정렬됩니다 | 행위자가 분명한 피동 | 시퀀서가 트랜잭션을 정렬합니다 |
| 사용자들의 자산들을 보호합니다 | 복수 "들" 남용 | 사용자 자산을 보호합니다 |
| 현재 마이그레이션을 하는 중에 있습니다 | "~하는 중에 있다" | 지금 마이그레이션하고 있습니다 |
| 체계적이고 효율적이며 전략적인 접근 | "~적" 연쇄, 내용 없음 | 실제 방법을 쓴다 |

| 팀 회의를 가졌습니다 | 팀 회의를 했습니다 |

| 업데이트가 되어졌습니다 | 업데이트됐습니다 (이중 피동 제거) |

## 3. 빈말: 배경, 출처, 중요성, 홍보, 결말

| 유형 | 원문 | 고치는 방향 |
| --- | --- | --- |
| 시대 배경 | 블록체인 기술이 빠르게 발전하는 오늘날, 보안의 중요성은 아무리 강조해도 지나치지 않습니다. | 지우고 바로 본론으로. 예: "지난달 감사에서 재진입(reentrancy) 취약점 2건이 나왔습니다." |
| 모호한 출처 | 업계 전문가들은 L2가 대세라고 입을 모읍니다. | 자료에 있는 출처를 밝히거나 문장을 지운다 |
| 중요성 주장 | 이는 생태계 확장에 중요한 역할을 합니다. | 무엇이 어떻게 달라지는지. 예: "이 브리지로 A 체인 사용자가 B 체인 dApp을 쓸 수 있습니다." |
| 홍보어 | 혁신적인 게임 체인저 솔루션 | 기능, 조건, 수치로 |
| 상투 결말 | 앞으로의 행보가 더욱 기대됩니다. | 지우거나 실제 다음 일정으로 |

## 4. AI 수사 습관

| 유형 | 원문 | 고치는 방향 |
| --- | --- | --- |
| 부정 병렬 | 이것은 단순한 지갑이 아니라 새로운 금융 경험입니다. | 실제 차이를 바로: "이 지갑은 앱 안에서 스왑과 스테이킹을 할 수 있습니다." |
| 셋씩 나열 | 빠르고, 안전하고, 편리한 (근거는 하나뿐) | 근거 있는 것만 남긴다 |
| 콜론 제목 | 가스비 최적화: 작은 차이가 만드는 큰 변화 | 가스비를 줄인 방법 |
| 질문형 전환 | 그렇다면 왜 이런 문제가 생길까요? | 이 문제는 ~ 때문에 생깁니다. |
| 줄표 | 새 버전은 — 예상대로 — 더 빠릅니다 | 쉼표, 괄호, 문장 나누기 |
| 꾸밈 과잉 | 문단마다 굵은 글씨, 이모지 불릿(✅🚀💡) | 강조는 정말 중요한 한두 곳만 |
| 문단 끝 요약 | 이처럼 ~는 ~에 있어 핵심적인 요소라고 할 수 있습니다. | 지운다 |

## 5. 완충 표현과 과잉 겸양

| 원문 | 고친 예 |
| --- | --- |
| ~할 수 있을 것으로 보입니다 | 추정이면 "~할 것으로 보입니다", 확정이면 "~합니다" |
| ~라고 할 수 있습니다 | ~입니다 |
| 어느 정도 개선될 수도 있을 것 같습니다 | 사실 상태에 맞는 한 가지로 |
| 확인해 드릴 수 있도록 하겠습니다 | 확인하겠습니다 |
| 문단마다 "참고 부탁드리겠습니다" | 한 번이면 충분하다 |

## 6. 챗봇 말투

독자에게 가는 글에 남으면 안 되는 표현이다. 지운다.

- 좋은 질문입니다 / 물론입니다!
- 말씀하신 내용을 바탕으로 정리해 드리겠습니다
- 도움이 되셨길 바랍니다
- 궁금한 점이 있으시면 언제든지 말씀해 주세요

## 7. 높임 수준 혼용과 종결 반복

- **혼용:** "배포는 금요일입니다. 롤백 절차는 아래를 참고해요. 담당자는 운영팀이다." → 상황에 맞는 하나로 통일한다.
- **종결 반복:** "지갑을 연결할 수 있습니다. 토큰을 스왑할 수 있습니다. 거래 내역을 확인할 수 있습니다." → "지갑을 연결하면 토큰 스왑과 거래 내역 확인을 한 화면에서 할 수 있습니다."

## 8. 용어와 표기

| 원문 | 문제 | 고친 예 |
| --- | --- | --- |
| 토큰을(를) 스왑합니다 | 조사 병기 | 토큰을 스왑합니다 |
| Solidity을 / Ethereum를 | 발음 받침과 조사가 안 맞음 | Solidity를(솔리디티) / Ethereum을(이더리움) |
| 지분 위임 예치 | 원어로 통용되는 용어를 억지 번역 | 스테이킹(staking) |
| 사용자(user)가 지갑(wallet)을 연결(connect)하면 | 일상어까지 영어 병기 | 사용자가 지갑을 연결하면 |

## 9. 과잉 교정: 고치다가 생기는 문제

AI 티를 지우다가 아래처럼 되면 되돌린다. oil-tone이 가장 강조하는 부분이다.

| 유형 | 원문(과잉 교정 결과) | 고친 예 |
| --- | --- | --- |
| 조사·어미를 깎은 전보체 | 배포 완료. 이슈 없음. 모니터링 중. (보고서·메신저가 아닌 블로그에서) | 배포를 마쳤고 지금까지 이슈는 없습니다. 당분간 모니터링하겠습니다. |
| 문장을 모두 짧게 자름 | 가스비가 올랐다. 사용자가 줄었다. 우리는 L2로 옮겼다. (인과가 사라짐) | 가스비가 오르면서 사용자가 줄었고, 그래서 L2로 옮겼다. |
| 접속어를 모두 지움 | 관계를 보여 주던 "그래서", "하지만"까지 지움 | 실제 관계를 나타내는 접속어는 남긴다 |
| 모든 문단을 개조식으로 | 설명과 인과가 목록으로 쪼개짐 | 이어지는 설명은 문단으로 |
| 사실까지 '자연스럽게' | "약 30% 감소" → "크게 줄었다" | 수치는 그대로 둔다 |
| 인사와 맺음까지 지운 공지 | "v2.3.1은 금요일 오후 3시에 배포합니다. QA는 목요일까지 회귀 테스트 부탁드립니다." (채널 공지에서) | 머리말과 핵심 항목 목록을 두고, 인사와 감사 한 줄은 남긴다 |
| 원문의 빈말을 '원문 존중'이라며 남김 | "Web3 대중화에 중요한 역할을 할 것으로 봅니다" | 빈말은 지키는 주장이 아니다. 지우거나 자료가 뒷받침하는 내용으로 바꾼다 |
